# Database Overview (Oracle HR Schema)
In this project, I utilize the Oracle HR (Human Resources) Sample Schema. This relational dataset provides a realistic environment to practice complex queries across multiple related tables.
The schema includes the following core tables:
- EMPLOYEES: Stores details of all staff members, including IDs, names, emails, salaries, and manager hierarchies.
- DEPARTMENTS: Contains information about various departments and their respective managers.
- JOBS: Lists job titles and salary ranges (minimum and maximum).
- JOB_HISTORY: Records the history of employees' roles and department changes over time.
- LOCATIONS: Physical addresses of the department offices.
- COUNTRIES & REGIONS: Geographic data used to organize locations globally.

---

## 1. SQL Fundamentals & Data Retrieval
- Basics: Database concepts, data types, and constraints (Primary/Foreign Key).
- Filtering & Sorting: Using WHERE clauses, logical operators (AND, OR, NOT), and ORDER BY.
- Restricting Data: Mastery of BETWEEN, IN, LIKE, and IS NULL conditions.

---

## 2. Data Transformation (Single Row Functions)
- String Manipulation: UPPER, LOWER, SUBSTR, INSTR, and REPLACE for data cleaning.
- Numeric & Date: Calculations using ROUND, TRUNC, MOD and date arithmetic with SYSDATE, ADD_MONTHS.
- Conversion & Null Handling: Expert use of TO_CHAR, TO_DATE, and null functions like NVL, COALESCE.

---

## 3. Advanced Querying & Relationships
- Joins: Combining data using INNER, LEFT, RIGHT, FULL, and SELF JOIN.
- Aggregation: Summarizing data with GROUP BY and filtering groups with HAVING.
- Subqueries: Utilizing single-row, multi-row, and correlated subqueries.
- Set Operators: Combining result sets with UNION, UNION ALL, INTERSECT, and MINUS.

---

## 4. Analytical Functions & Database Objects
- Window Functions: Advanced analysis using ROW_NUMBER, RANK, DENSE_RANK, LAG, and LEAD.
- Data Control (DDL/DML/TCL): Managing table structures (CREATE, ALTER), manipulating data (INSERT, UPDATE), and controlling transactions (COMMIT, ROLLBACK).
- Views & CTEs: Creating virtual tables and using Common Table Expressions (WITH clause) for readable code.
- Regular Expressions: Pattern matching with REGEXP_LIKE and REGEXP_SUBSTR.

---

## 5. Database Design
- ER Diagrams: Understanding entities, relationships, and cardinality.
- Normalization: Applying 1NF, 2NF, and 3NF principles for efficient database architecture.
